# Custom sounds

- `ringtone.mp3` — incoming call / video call ringtone  
  Source: **Pat My Back - Righton.mp3** (client “Rington”). Loops while the incoming-call overlay is showing.
- `message-chime.mp3` — new chat message chime  
  Source: **Ding 4.mp3** (highest note of Dings 1–4, as requested).

If a file is missing, the app falls back to a soft built-in Web Audio tone.
